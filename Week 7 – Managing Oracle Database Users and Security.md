Week 7 – Managing Oracle Database Users and Security
Students will manage the Oracle database environment by creating Database Users,
Tablespaces, Roles, and Privileges. They should implement user management operations
such as CREATE USER, DROP USER, GRANT, REVOKE, and assign appropriate
access permissions to ensure database security and proper user management.

``` sql 
SELECT ISSUE_ID FROM BOOK_ISSUE
UNION
SELECT  ISSUE_ID FROM BOOK_RETURN;

SELECT  ISSUE_ID FROM BOOK_ISSUE
INTERSECT
SELECT  ISSUE_ID FROM BOOK_RETURN;

SELECT  ISSUE_ID FROM BOOK_ISSUE
MINUS
SELECT  ISSUE_ID FROM BOOK_RETURN;
```
